# Changes in this upgrade

1. Multiple direct schedules are retained as individual options.
2. Search controls include transport mode, time-of-day window, departure-after time, and maximum budget.
3. The city catalogue includes all state/UT capitals plus the original sample cities.
4. The backend exposes `/states` and returns city state metadata.
5. Dynamic estimates factor in approximate festive periods, weekend/Friday demand, peak periods, weekday traffic, monsoon road delay, and cab overhead.
6. Added estimates are explicitly labelled; no live provider data is claimed.
